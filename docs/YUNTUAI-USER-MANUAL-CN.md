### 2. 项目背景

YunTuAI 控制台 由 深圳市浩瀚云图信息科技有限责任公司 研发，定位为本地 AI 代理网关桌面控制中心。
客户端基于 Tauri 2 与 React 19 构建，与本机 OpenClaw 网关进程协同，提供会话聊天、多 Agent 管理、任务编排、网关监管、技能工坊、设备授权与操作审计等能力。
数据默认留存本机；支持云图中转站发行版（8 位数字登录密码）与 DeepSeek 直连发行版（字母+数字密码），API Key 配置方式因发行档而异。
内置 Tesseract OCR，图片与纯图片 PPT 附件优先走本地文字识别，无需依赖外部视觉模型 API。

| 能力域 | 简要说明 |
| --- | --- |
| 会话聊天 | 多会话、流式回复、附件 OCR、命令审批 |
| Agent | 多实例、模型绑定、技能装载 |
| 任务办事 | 步骤流水线、产出交付、重跑 |
| 网关 | 启停、健康检查、冲突回收 |
| 技能 | 向导生成、社区安装、模块管理 |
| 授权审计 | license 绑定、Owner 日志 |

- 与纯 Web 聊天客户端不同，本软件必须与本机网关协同，离线时仅可查看历史，无法调用模型。
- 技能与工作区文件均存储在用户可访问目录，便于备份、迁移与二次开发。
- Owner 机制将高危运维能力与日常登录分离，符合企业最小权限原则。

## 4. 运行环境

部署前请确认硬件、操作系统与网络条件满足下列要求，以降低首次启动失败或网关内存不足的风险。

### 4.1 硬件环境

建议配置：CPU x86_64 双核及以上（推荐四核 2.0GHz+）；内存 4GB 及以上（推荐 8GB）；硬盘可用空间 2GB 及以上（推荐 10GB，含技能包与 AI 产出）；显示器分辨率 1280×720 及以上。

| 项目 | 最低要求 | 推荐配置 | 说明 |
| --- | --- | --- | --- |
| 处理器 | x86_64 双核 | 四核 2.0GHz+ | 首次解压内置运行时占用 CPU |
| 内存 | 4GB | 8GB+ | 网关内存上限可在设置中配置 |
| 硬盘 | 2GB 可用 | 10GB+ | 含 openclaw-data、workspace、技能目录 |
| 显示器 | 1280×720 | 1920×1080 | 侧栏与任务进度需足够宽度 |
| 网络 | 安装/更新需联网 | 稳定宽带或内网 | 对话推理可走本地网关转发 |

**硬件相关说明**

- 首次启动需解压内置 Node/OpenClaw 运行时，建议在 SSD 上安装以缩短等待时间。
- 若本机同时运行大型 IDE 或虚拟机，建议将网关内存上限设为 512MB～1024MB 并关闭无关占用。
- 语音听写（macOS）需授予麦克风权限；OCR 依赖安装包内置 Tesseract 与 chi_sim/eng 语言包。

[截图：运行环境检测界面]
### 4.2 软件环境

支持 Windows 10/11（64 位）与 macOS 12.0+（Intel / Apple Silicon）；无需用户单独安装 Node.js 或 Python。
关闭主窗口时应用最小化至系统托盘而非退出进程，以便保持网关连接与后台任务。

### 4.3 网络与防火墙

客户端需访问本机回环地址与可选外网 API；企业环境请提前放行下列通信。

| 通信类型 | 目标 | 说明 |
| --- | --- | --- |
| 本机网关 | 127.0.0.1:18789（默认） | 必须放行，禁止被安全软件拦截 |
| 模型 API | 服务商 HTTPS 端点 | 直连版必需；中转站视部署而定 |
| 应用更新 | 发行 CDN HTTPS | 检查更新与下载 MSI 时使用 |
| 技能同步 | 服务端 HTTPS | 办事能力「同步精选技能」时使用 |

- VPN 或全局代理可能影响本机回环检测，异常时尝试暂时关闭代理测试。
- 严格白名单环境应同时将更新通道域名加入允许列表，否则无法自动升级。
- 离线内网部署需提前准备完整安装包、license 与离线技能包，无法依赖社区在线安装。

| 操作系统 | 版本 | 备注 |
| --- | --- | --- |
| Windows | 10 / 11 64 位 | 建议安装最新累积更新；UAC 提示时请允许 |
| macOS | 12.0+ | 听写需麦克风权限；DMG 安装后首次打开需在安全性设置中允许 |

| 内置组件 | 用途 |
| --- | --- |
| OpenClaw 网关 | 本机 AI 代理服务，默认端口 18789 |
| Tesseract OCR | 图片、幻灯片文字预识别 |
| SQLite | 本地账户与会话元数据 |

**软件相关说明**

- 发行安装包已捆绑运行时，请勿与系统 PATH 中的外置 OpenClaw 安装混用，冲突时可在设置中「回收控制权」。
- 直连版需在设置中配置 API Key；中转站版由服务端绑定，用户侧通常无需填写 Key。

**4.2 补充：目录与权限**

Windows 默认将用户数据写入 %APPDATA% 或安装目录旁 openclaw-data；macOS 位于 Application Support。

若企业策略禁止写入 AppData，请在安装时选择具有写权限的自定义路径，并确保杀毒软件未隔离网关子进程。

多用户共用同一 Windows 账户时，会话与授权记录共享，不建议在公共终端保存登录状态。

虚拟机或容器环境需为网关分配足够内存，并放行本地回环 127.0.0.1:18789 通信。

## 5. 安装与卸载

请从授权渠道获取对应发行档的安装包，以下步骤以 Windows MSI 为例，macOS DMG 流程类似。

### 5.1 安装步骤

安装包文件名通常包含版本号与发行档标识；安装前请关闭正在运行的旧版本实例。
Windows 与 macOS 安装路径不同，但首次启动后的授权与配置流程一致。

**第 1 步：** 双击 MSI 安装包（如 YunTuAI_1.3.8_x64_zh-CN.msi）；若出现 UAC 提示，点击「是」。
**第 2 步：** 在欢迎页确认默认路径 %LOCALAPPDATA%\YunTuAI\；可点击「浏览…」选择 D 盘等自定义文件夹。
**第 3 步：** 确认目标目录有读写权限后点击「安装」；安装到其他盘若卸载出现 Config.Msi 权限错误，请以管理员重试或运行 uninstall-yuntuai-clean.ps1。
**第 4 步：** 等待进度条完成；在结束页勾选「安装完成后启动 YunTuAI」，点击「完成」。
**第 5 步：** 首次启动将解压内置运行时（约 1～3 分钟），按引导完成设备授权、API Key（直连版）及管理员注册/登录。
**第 6 步：** 顶栏显示「本机 · 已连接」后即可使用会话与办事；也可先进入主界面，在「软件设置 → 本机服务」中重连。

**安装注意事项**

- 欢迎页必须在点击「安装」前选好目录；安装程序会在该路径下写入 exe、openclaw-portable 与数据目录。
- 企业环境若限制 AppData，请用「浏览」改到 D:\YunTuAI 等可写路径，勿选只读或受控目录。
- 安装过程中请勿强制结束进程，以免内置运行时解压不完整。
- 覆盖安装旧版 MSI 会保留 openclaw-data 与账户数据；安装完成后可在设置中检查应用更新。

### 5.2 卸载步骤

卸载前请备份工作区产出、openclaw-data 配置及重要会话导出，卸载程序默认不保留用户数据。

**第 1 步：** 在系统托盘找到 YunTuAI 图标，右键选择「退出」，确认进程完全关闭（任务管理器中无 yuntu 相关进程）。
**第 2 步：** Windows：打开「设置 → 应用 → 已安装的应用」，搜索 YunTuAI，点击「卸载」并按向导完成。
**第 3 步：** 若需彻底清理残留数据，在备份后手动删除用户目录下的 openclaw-data、workspace 及 Application Support 中的相关文件夹。
**第 4 步：** macOS：将应用程序拖入废纸篓，并清理 ~/Library/Application Support 下与 YunTuAI 相关的目录。

**卸载注意事项**

- 卸载不会自动注销设备授权记录，重新安装同一设备通常可沿用原 license.dat（在有效期内）。
- 若仅升级版本，建议使用应用内「检查更新」或覆盖安装 MSI，无需先卸载。

## 6. 软件功能详解

本章按模块介绍 YunTuAI 控制台 1.3.8 的主要功能与典型操作流程。各小节配有界面截图占位，便于对照实际操作。

### 6.1 启动与登录

**功能描述：** 涵盖应用启动屏、内置运行时解压、设备授权门禁、用户注册/登录、记住用户名、Owner 代登与 Owner 解锁。
首次使用须创建管理员账户；中转站发行版密码须恰好 8 位纯数字，直连发行版须至少 8 位且同时含英文字母与数字。
[截图：启动屏与进度提示界面]

### 6.1.1 首次启动引导

首次启动时，应用将自动准备本机 OpenClaw 运行时环境，期间顶栏或启动屏会显示进度文案，请耐心等待。

**第 1 步：** 从开始菜单或桌面快捷方式启动应用，观察启动屏「正在准备本机环境…」等状态提示；首次解压约需 1～3 分钟。
**第 2 步：** 若本机尚未激活授权，将自动进入「设备授权」页，按 6.1.3 节完成 license.dat 粘贴与激活。
**第 3 步：** 授权通过后进入「云图 AI」登录页：新用户点击注册，填写用户名与符合发行档规则的密码；已有账户直接登录。
**第 4 步：** 直连版用户需在进入主界面前或之后，于设置中配置 API Key（见 6.9.1 节）；中转站版通常已绑定服务端 Key。
**第 5 步：** 登录成功后进入主工作区；若网关尚未连接，可按提示选择后台连接或前往仪表盘手动启动网关。

| 界面元素 | 说明 |
| --- | --- |
| 启动进度 | 显示解压、网关初始化等阶段 |
| 记住用户名 | 勾选后 7 天内自动填充用户名（不保存密码） |
| 注册/登录切换 | 首次部署建议先注册管理员账户 |

[截图：首次注册与登录界面]
### 6.1.2 Owner 解锁

**功能描述：** Owner 为深层运维角色，解锁后可访问运行日志、高级控制台、用户管理、深度运维等敏感功能。
Owner 密码与登录密码相互独立；操作完成后建议及时「锁定」以降低本机误操作风险。

**第 1 步：** 点击顶栏用户菜单，选择「Owner 解锁」；或在「软件设置」页找到「Owner 开发权限」卡片。
**第 2 步：** 在弹出面板中输入 Owner 密码，点击「解锁开发权限」；校验通过后顶栏或设置页将显示已解锁状态。
**第 3 步：** 解锁后可侧栏进入「运行日志」、设置中「深度运维（Owner）」及高级控制台；使用完毕点击「锁定」或等待会话过期。

**Owner 相关说明**

- 用户忘记登录密码时，具备 Owner 代登能力的安装包可由 Owner 在登录页「代为登录」目标账户。
- Owner 解锁状态仅在本机会话有效，重启应用后需重新解锁。
- 企业环境应限制知晓 Owner 密码的人员范围，并定期轮换密码。

[截图：Owner 解锁面板界面]
### 6.1.3 设备授权

**功能描述：** 通过 license.dat（JSON 格式授权文件）将软件绑定至本机机器指纹，支持首次激活与续费更换。

**第 1 步：** 在设备授权页复制「机器指纹」字符串，通过授权渠道提交给管理员或授权系统。
**第 2 步：** 获得 license.dat 完整 JSON 内容后，粘贴至授权输入框（勿截断或修改字段），点击「激活设备」。
**第 3 步：** 激活成功后界面显示授权有效期与状态徽章；到期前可在「设置 → 设备授权」使用「续费激活」粘贴新授权。

| 状态 | 含义 | 建议操作 |
| --- | --- | --- |
| 未授权 | 尚未激活 | 提交指纹申请 license.dat |
| 已激活 | 在有效期内 | 正常使用 |
| 即将到期 | 临近过期 | 提前续费激活 |
| 已到期 | 授权失效 | 粘贴新 license 后续费 |

[截图：设备授权激活界面]
### 6.1.4 退出与重新登录

用户可在顶栏菜单选择退出登录；退出后本地草稿会话保留，但发送消息需重新鉴权。

**第 1 步：** 点击顶栏用户头像或用户名，在下拉菜单中选择「退出登录」。
**第 2 步：** 确认后返回登录页；勾选「记住用户名」可保留账户名方便下次输入。
**第 3 步：** 若需切换账户，使用另一用户名登录即可；原账户会话列表仍保存在本机，除非 Owner 删除账户。

**6.1 安全建议**

在共享设备上勿勾选长期记住密码类选项（本软件仅记住用户名 7 天）。

Owner 密码与登录密码应使用不同字符串，并定期更换。

设备授权文件 license.dat 含签名信息，请勿通过非加密渠道传播。

发现异常 Owner 代登记录时，应立即审计运行日志并强制受影响用户改密。

### 6.2 仪表盘/首页

**功能描述：** 从左侧栏底部「仪表盘」进入，集中展示本机服务连接、网关进程健康、近期办事任务摘要，是日常运维的首选入口。
仪表盘与顶栏网关芯片、右侧任务进度侧栏数据联动，便于快速判断「能否发消息」「网关是否冲突」。
[截图：仪表盘总览界面]

### 6.2.1 服务连接状态

「服务连接」卡片反映客户端与本地 OpenClaw 网关的 WebSocket/HTTP 连接质量，是发送消息与附件的前置条件。

**第 1 步：** 打开仪表盘，查看「服务连接」卡片标题旁的状态点：绿色为已连接，黄色为连接中，红色为异常，灰色为未连接。
**第 2 步：** 若状态异常或未连接，点击卡片内「重新连接」按钮；同时观察顶栏「本机 · …」芯片与延迟数值是否恢复。
**第 3 步：** 仍无法连接时，前往 6.6 节检查网关是否已启动，或在设置 → 本机服务中执行「连接服务」与「复制诊断」。

| 状态文案 | 含义 |
| --- | --- |
| 已连接 | 可正常发送消息与附件 |

### 6.2.2 网关进程监控

「网关进程」卡片展示本机 OpenClaw 网关的运行状态、进程 PID 及运行时健康结论，支持一键启停与健康检查。

**第 1 步：** 在仪表盘「网关进程」区域查看状态：运行中 / 已停止 / 外部冲突等，并记录 PID（便于技术支持定位）。
**第 2 步：** 若提示「检测到外部网关进程冲突」，说明 18789 端口存在未受 YunTuAI 监管的进程，应点击「回收控制权」。
**第 3 步：** 需要时可使用卡片上的启动、停止、重启、健康检查按钮；详细说明见 6.6.2 节。

**网关进程说明**

- 「回收控制权」将终止冲突进程并由 YunTuAI 重新拉起受管网关，操作前请确认无其他应用依赖该端口。
- 健康检查失败时，可结合「运行日志」（Owner 解锁后）查看具体错误栈。

### 6.4 会话聊天

**功能描述：** 核心对话模块，支持多会话管理、流式回复、深度思考折叠块、附件上传（含内置 OCR）、语音听写、模型选择与命令执行审批。
发送消息前须确保本机服务已连接；附件单文件上限 48MB，图片与纯图片 PPT 将优先经内置 OCR 预识别后注入上下文。
[截图：会话聊天主界面]

### 6.4.1 新建会话

每个会话维护独立的对话历史与可选的办事任务绑定，适合按项目或主题拆分交流。

**第 1 步：** 点击左侧会话列表顶部「新对话」，或使用快捷键 Ctrl+N（Windows）/ Cmd+N（macOS）。
**第 2 步：** 界面进入撰写模式，输入框居中；输入首条用户消息并发送后，系统自动创建会话条目。
**第 3 步：** 新建会话默认绑定当前选中的 Agent 与模型；可在发送前通过模型选择器调整。

**会话管理提示**

- 侧栏支持搜索会话标题，双击条目可重命名。
- 删除会话需二次确认，删除后本地历史不可恢复，重要内容请先导出。

### 6.4.2 发送消息与流式回复

助手回复以流式方式逐字呈现；生成过程中可点击「停止」中断。部分模型支持「深度思考」折叠块展示推理过程。

**第 1 步：** 在底部输入框键入内容：Enter 发送，Shift+Enter 换行；长文本建议先在外部编辑器整理后粘贴。
**第 2 步：** 发送后观察消息区流式输出；若 Agent 请求执行 shell 命令，将弹出审批条（允许一次 / 始终允许 / 拒绝）。
**第 3 步：** 含「深度思考」的回复会在正文上方显示可折叠块，点击标题可展开或收起推理过程。

| 交互 | 行为 |
| --- | --- |
| Enter | 发送当前输入 |
| Shift+Enter | 输入框内换行 |
| 停止 | 中断当前生成 |
| 命令审批 | 用户确认后方可在本机执行命令 |

[截图：流式回复与思考块界面]
### 6.4.3 历史记录管理

左侧会话列表保存本机会话元数据；右侧「会话信息」面板提供导出、清空与重载等维护操作。

**第 1 步：** 使用列表顶部搜索框按标题过滤会话；单击选中，双击进入重命名状态。
**第 2 步：** 右键或操作菜单可删除会话；删除前系统提示不可恢复，请谨慎操作。
**第 3 步：** 打开右侧「会话信息」，可导出会话记录、清空当前会话消息或从网关重新拉取远程状态。

### 6.4.4 附件上传

**功能描述：** 支持通过回形针按钮或拖拽添加文件；图片、含图幻灯片将自动触发内置 OCR，识别文本注入消息上下文后再发送给 Agent。
须本机服务已连接方可携带工作区附件发送；超过 48MB 的文件将被拒绝并提示。

**第 1 步：** 点击输入区回形针图标选择文件，或将文件拖入输入区上方拖放区域。
**第 2 步：** 添加后附件列表显示文件名与大小；图片/PPT 处理期间可能显示 OCR 进度或成功条数提示。
**第 3 步：** 确认附件无误后发送消息；正文中将附带 OCR 预识别块或文档预提取摘要，供 Agent 理解附件内容。

**附件与 OCR 说明**

- 纯图片 PPT（无文本层）完全依赖 OCR，识别质量受分辨率与语言包影响。
- DeepSeek 直连模型为纯文本通道，OCR 是官方图片理解路径，请勿依赖视觉模型 API 替代。
- 发送失败提示「请先绑定办事会话」时，请使用 Ctrl/Cmd+Shift+S 绑定或等待网关就绪后重试。

[截图：附件上传与 OCR 提示界面]
### 6.4.5 其他输入能力

输入区还提供产出目录快捷入口、语音听写与模型切换，便于长任务与多模型协作。

**第 1 步：** 点击文件夹图标：快速打开或设置 AI 产出目录（与设置 → 输出目录一致）。
**第 2 步：** 点击麦克风图标：启动语音听写（macOS 需麦克风权限），识别结果填入输入框。
**第 3 步：** 使用模型选择器切换当前会话模型或选择 Auto，由系统按策略自动路由。

当对话上下文 token 估算过高时，界面会提示建议「压缩上下文」后再继续长任务，可在任务侧栏或网关相关操作中执行压缩。
### 6.4.6 命令审批与安全

当 Agent 提议在本机执行 shell 命令时，客户端会弹出审批条，防止未经确认的系统变更。

**第 1 步：** 阅读审批条中的命令摘要与风险说明，确认与当前任务相关。
**第 2 步：** 选择「允许一次」仅执行本条命令；「始终允许」在本会话内不再询问同类命令（谨慎使用）。
**第 3 步：** 选择「拒绝」将中止该工具调用，Agent 可能改用其他方式完成任务或提示无法继续。

**6.4 会话最佳实践**

长文档分多次提问，避免单次粘贴超大文本导致上下文溢出。

办事类任务先绑定办事会话（Ctrl/Cmd+Shift+S），再上传工作区附件。

敏感文件上传前确认 OCR 文本预览无多余泄露内容。

定期导出重要会话，防止本机数据库损坏导致历史丢失。

使用「深度思考」模型时注意响应耗时增加，适合复杂推理而非简单问答。

| 消息类型 | 展示特征 | 说明 |
| --- | --- | --- |
| 用户消息 | 右侧或高亮气泡 | 含文本与附件摘要 |
| 助手消息 | 左侧主内容区 | 支持 Markdown 渲染 |
| 思考块 | 可折叠标题「深度思考」 | 展示推理过程 |
| 系统提示 | 居中或浅色条 | 连接、OCR、错误等 |

### 6.5 任务编排与进度

**功能描述：** 右侧「任务进度」侧栏追踪办事任务的步骤流水线、完成状态与交付物路径，与仪表盘「近期办事」及会话聊天联动。
用户在对话中下达办事类指令时，系统自动创建任务并展示分步进度，体现「发任务 → 办事 → 交结果」的产品体验。
[截图：任务进度侧栏界面]

### 6.5.1 任务创建

任务可由对话自然触发，也可通过快捷键将当前会话绑定为办事会话。

**第 1 步：** 在已连接本机服务的会话中，发送包含办事意图的指令（如生成报告、批处理文件等），网关返回后将创建本地任务记录。
**第 2 步：** 使用 Ctrl/Cmd+Shift+S 可将当前会话绑定为办事会话，便于后续携带工作区附件执行多步操作。
**第 3 步：** 任务创建后右侧侧栏自动展开（若已收起，可点击侧栏把手打开），显示任务标题与步骤列表。

### 6.5.2 步骤追踪

步骤流水线以时间顺序展示各子步骤状态，便于判断 Agent 执行进度与卡点。

**第 1 步：** 在任务进度侧栏查看步骤列表，每步带有状态图标：等待、进行中、成功、失败、跳过。
**第 2 步：** 点击展开步骤可查看详细日志摘要或工具调用说明（视网关返回而定）。
**第 3 步：** 执行中步骤会动态更新；若长时间停留「进行中」，可结合运行日志或连接诊断排查网关负载。

[截图：步骤流水线界面]
### 6.5.3 完成状态与重跑

任务结束后侧栏展示总结卡片，成功时提供产出路径，失败时提供重跑入口。

**第 1 步：** 任务成功：显示「任务已完成」，可点击「打开目录」在资源管理器中定位产出，或「复制路径」分享路径字符串。
**第 2 步：** 任务失败：显示失败原因摘要，点击「重跑本任务」将基于保留的提示模板重新发起（会话需仍有效）。
**第 3 步：** 部分完成：部分步骤成功但整体未达标，建议查看会话内 Agent 说明后决定是否手动续办或重跑。

### 6.5.4 网关相关操作

任务侧栏底部提供与网关维护相关的快捷操作，减少在设置页与对话页之间切换。

**第 1 步：** 「压缩上下文」：向网关请求压缩当前会话上下文，降低 token 占用，适合长任务中途优化。
**第 2 步：** 「复制连接诊断」：将连接状态、延迟、网关版本等诊断信息复制到剪贴板，便于提交工单。
**第 3 步：** 「刷新网关订阅」：重新订阅网关事件流，解决侧栏进度长时间不更新的情况。

**6.5 任务生命周期**

创建：用户发送办事指令或绑定办事会话后，网关分配 task id 并推送步骤事件。

执行：侧栏步骤随 WebSocket 事件更新；会话内可查看 Agent 中间输出。

交付：成功步骤写入产出路径；用户通过「打开目录」验收文件。

结束：完成、失败或取消后任务进入历史，仪表盘「近期办事」保留摘要。

重跑：失败任务保留 replay 模板时，一键重跑无需重新口述需求。

| 侧栏按钮 | 作用 | 使用时机 |
| --- | --- | --- |
| 压缩上下文 | 缩减会话 token | 长对话中途卡顿 |
| 复制连接诊断 | 导出诊断 JSON | 提交工单 |
| 刷新网关订阅 | 重绑事件流 | 进度条冻结 |
| 重跑本任务 | 重新执行 | 步骤失败可恢复 |

### 6.6 网关控制

**功能描述：** 统一管理本机 OpenClaw 网关的启停、健康检查、连接状态展示、端口冲突回收与 Owner 高级控制台入口。
网关是会话、任务、技能与 Agent 的数据面中枢，未连接时大部分功能不可用或仅可本地草稿。
[截图：网关控制面板界面]

### 6.6.1 连接状态查看

顶栏「本机 · 已连接/未连接」芯片是全局连接状态的最快指示，配合延迟数值判断服务质量。

**第 1 步：** 观察顶栏左侧芯片文案与颜色：已连接为绿色系，未连接或异常为警告色。
**第 2 步：** 鼠标悬停可查看延迟毫秒数；延迟持续偏高时检查本机 CPU/内存或上调网关内存上限。
**第 3 步：** 断开时点击芯片或侧栏提示中的「重连」，快捷键 Ctrl/Cmd+Shift+R 亦可触发重连。

### 6.6.2 启动/停止/重启网关

仪表盘「网关进程」卡片与「软件设置 → 本机服务」均提供网关服务控制按钮组。

**第 1 步：** 若网关未运行，点击「启动」并等待状态变为「运行中」；首次启动可能伴随运行时自检。
**第 2 步：** 维护或更换配置（如 API Key、内存上限）后，使用「重启」使配置生效。
**第 3 步：** 临时排障可「停止」网关，确认无任务执行中后再操作；停止后顶栏将显示未连接。
**第 4 步：** 定期点击「健康检查」验证网关 HTTP/WebSocket 端点可用性。
**第 5 步：** 遇端口冲突时优先「回收控制权」，由 YunTuAI 接管 18789 端口上的网关进程。

### 6.6.3 连接参数与自动恢复

在「软件设置 → 本机服务连接」可配置自动重连、健康检测间隔及手动诊断导出。

**第 1 步：** 勾选「自动重连」与「健康检测」，以便睡眠唤醒或短暂网络抖动后自动恢复连接。
**第 2 步：** 修改网关地址或 Token 后点击「连接服务」立即应用；异常时使用「复制诊断」收集信息。
**第 3 步：** 直连版在此分区还可进入模型配置、网关内存上限等子面板（详见 6.9 节）。

高级控制台面向运维人员，误操作可能影响本机服务稳定性，请在熟悉 OpenClaw 概念后使用。

**第 1 步：** Owner 解锁后，从设置或侧栏入口打开「高级控制台」。
**第 2 步：** 在概览页查看网关版本、活跃连接与资源占用；在 Agent/技能页进行深度配置。

**6.6 网关排障要点**

现象：顶栏一直「连接中」—— 等待 60 秒后重连，检查是否有杀毒软件拦截子进程。

现象：频繁断开 —— 开启自动重连，检查本机睡眠策略是否杀死后台进程。

现象：18789 端口冲突 —— 使用回收控制权，或手动结束占用进程后重启网关。

现象：健康检查失败 —— 查看运行日志中 openclaw 启动错误，必要时重装运行时。

配置变更：修改 API Key、内存上限、Provider 后务必重启网关。

| 控制项 | 位置 | 说明 |
| --- | --- | --- |
| 启动 | 仪表盘/设置 | 拉起网关主进程 |
| 停止 | 同上 | 释放端口与内存 |
| 重启 | 同上 | 应用配置变更 |
| 健康检查 | 同上 | 探测 HTTP/WS 端点 |
| 回收控制权 | 设置/提示条 | 解决外部进程冲突 |

### 6.8.4 审计使用建议

企业用户应建立定期巡检制度，将审计与账户权限管理结合，降低内部误用与凭证泄露风险。

- 建议每月导出或备份运行日志摘要，留存至少一个授权周期。
- 发现异常登录、频繁 Owner 解锁或未知 CLI 调用时，应立即修改登录密码并轮换 Owner 密码。
- 离职人员账户应由 Owner 在「深度运维 → 用户管理」中禁用或删除。
- 审计日志仅覆盖本机记录，分布式汇总需另行对接 SIEM（超出本手册范围）。

| 审计事件类型 | 典型内容 | 查看条件 |
| --- | --- | --- |
| 登录/登出 | 用户名、时间戳 | 运行日志 |
| Owner 解锁 | 操作者、结果 | Owner 解锁后 |
| CLI 调用 | 命令摘要 | Owner 解锁后 |
| 授权变更 | 激活/续费 | 设备授权页历史 |

### 6.9.1 API Key 配置

DeepSeek 直连发行版须在本机配置 API Key，保存后写入服务数据目录 `.env` 文件；中转站发行版通常由服务端绑定，界面可能仅显示只读状态。

**第 1 步：** 打开「软件设置 → 本机服务 → 模型配置」面板。

**第 3 步：** 保存后若提示需重启网关，请返回本机服务页点击「重启」；也可使用「从 .env 重新加载」在不重启情况下尝试热加载。

**API Key 说明**

- Key 仅存储于本机，不会上传至 YunTuAI 公有云（中转站模式由服务商托管另有协议）。
- 切换默认模型或 Provider 后，网关可能自动重启以应用新路由配置。
- Key 失效时对话页将提示「尚未配置 API Key」或上游 403，见第 7 章 FAQ。

### 6.9.5 其他设置项

以下子面板均位于「软件设置」内，按功能分区排列；各子项操作相互独立，修改后注意是否需要重启网关。
子节 6.9.5.1～6.9.5.6 分别对应应用更新、密码、托盘、内存、办事能力与 Owner 运维，每项均给出三步标准操作。

### 6.9.5.1 应用更新

通过发行 CDN 检查并安装 MSI 新版本；安装过程会替换主程序二进制，故须先停止 AI 生成。

**第 1 步：** 进入「软件设置 → 应用更新」面板。
**第 2 步：** 点击「检查更新」获取最新版本信息。
**第 3 步：** 若有新版本，点击「安装新版本」并按提示完成 MSI 安装后重启。

### 6.9.5.2 修改登录密码

修改当前登录账户密码，需校验旧密码；新密码须满足界面实时显示的发行档规则。

**第 1 步：** 进入「软件设置 → 修改登录密码」。
**第 2 步：** 填写当前密码、新密码与确认密码（规则随发行档显示）。
**第 3 步：** 点击「保存新密码」，成功后下次登录使用新密码。

### 6.9.5.3 启动与托盘

配置开机自启与关闭主窗口行为；托盘模式便于后台保持网关连接。

**第 1 步：** 进入「软件设置 → 启动与托盘」。
**第 2 步：** 勾选或取消「开机自动启动（后台运行，不显示主窗口）」。
**第 3 步：** 关闭主窗口将最小化至托盘；托盘左键显示主窗口，右键可退出。

### 6.9.5.4 网关内存上限

限制本机 OpenClaw 网关进程可用内存上限，过低可能导致长任务 OOM，过高可能影响其他应用。

**第 1 步：** 进入「软件设置 → 本机服务 → 网关内存上限」。
**第 2 步：** 在 256MB～4096MB 预设中选择适合本机的值。
**第 3 步：** 保存后重启网关使配置生效。

### 6.9.5.5 办事能力

从服务端同步精选技能包，并在模块管理中启用或卸载办事相关扩展。

**第 1 步：** 进入「软件设置 → 办事能力」。
**第 2 步：** 点击「同步精选技能」从服务端拉取技能包。
**第 3 步：** 点击「打开模块管理」查看模块启用与卸载状态。

### 6.9.5.6 深度运维（Owner）

Owner 专属分区，可接管本机服务进程、读取底层配置、管理本地用户账户，操作风险较高。

**第 1 步：** Owner 解锁后进入「深度运维（Owner）」分区。
**第 2 步：** 可「接管本机服务」、读取配置、管理用户账户。
**第 3 步：** 操作完成后建议「锁定」Owner 权限。

**6.9.5 补充说明**

- 应用更新安装前须停止当前 AI 生成，否则会提示「请等待当前回复完成或点击停止后再更新」。
- 中转站版修改密码须满足 8 位纯数字；直连版须字母与数字组合，界面会实时校验并提示。
- 网关内存 256MB 适合轻量对话，4096MB 适合长上下文或多工具并行，请按本机物理内存酌情选择。
- 深度运维中的「接管本机服务」仅限 Owner，操作不当可能导致网关配置被覆盖，执行前请确认。

### 6.1.5 登录场景示例

下列场景帮助不同角色快速完成首次或重复登录流程。

| 场景 | 操作要点 |
| --- | --- |
| 新部署管理员首次使用 | 注册 → 设备授权 → 配置 Key（直连）→ 登录 |
| 普通员工首次使用 | 向管理员索取账户 → 登录 → 无需 Owner |
| 用户忘记密码 | 联系 Owner 代登或重置密码 |
| 会话过期 | 重新登录，无需重新授权设备 |
| 更换电脑 | 新机器重新激活 license，账户数据不自动迁移 |

- 中转站用户注册时界面会提示「8 位数字密码」，不符合规则将无法提交。
- 直连用户密码须同时包含字母与数字，长度不少于 8 位。
- Owner 代登入口仅在发行包启用紧急代登能力时显示，见安装渠道说明。

### 6.2.4 数据刷新说明

仪表盘数据来自本机网关与本地任务存储，部分指标不会自动秒级刷新。

**第 1 步：** 切换回仪表盘页签时，服务连接状态会自动重新探测。
**第 2 步：** 网关 PID 在启停操作后约 1～2 秒内更新，若未变请点击浏览器式刷新（切换页签）。
**第 3 步：** 近期办事列表按更新时间倒序，默认展示最近若干条，完整历史请在任务侧栏查看。

### 6.3.5 多 Agent 协作模式

可在不同会话中绑定不同 Agent，实现并行处理多个工作流。

- 会话 A 使用「写作 Agent」生成文档，会话 B 使用「数据 Agent」分析表格，互不干扰。
- 顶栏切换 Agent 仅影响**新建**会话，已打开会话仍使用创建时的 Agent 绑定。
- 删除 Agent 前请确认无进行中任务引用该 Agent，否则重跑可能失败。

### 6.4.7 导出与备份

重要会话建议定期导出，避免本机数据库异常导致不可恢复。

**第 1 步：** 打开目标会话，展开右侧「会话信息」面板。
**第 2 步：** 选择「导出」或等效操作，将记录保存为 Markdown/文本文件到安全位置。
**第 3 步：** 企业环境可配置定期备份 openclaw-data 整个目录（需停机或确保无写入冲突）。

### 6.4.8 语音听写（macOS）

macOS 用户可通过麦克风将语音转为输入框文字，适合快速口述需求。

**第 1 步：** 首次点击麦克风时，系统可能请求麦克风权限，请在「系统设置 → 隐私」中允许。
**第 2 步：** 点击麦克风开始听写，再次点击或停顿后结束，识别结果填入输入框可编辑再发送。
**第 3 步：** 嘈杂环境可能影响识别准确率，重要指令建议文字确认后发送。

### 6.5.5 办事会话绑定详解

办事会话是携带工作区文件、执行多步工具调用的专用绑定关系。

- 未绑定办事会话时发送纯文本问答不受影响。
- 上传工作区附件或触发工具链时，系统可能提示绑定；使用 Ctrl/Cmd+Shift+S 主动绑定可避免中途失败。
- 绑定后侧栏显示任务进度；解绑或切换会话不会自动取消已运行中的网关任务。

### 6.6.5 连接诊断字段说明

「复制连接诊断」输出 JSON 含下列常见字段，供技术支持快速定位。

| 字段 | 含义 |
| --- | --- |
| connState | connected / connecting / error 等 |
| gatewayPid | 当前或最近网关进程号 |
| latencyMs | 最近一次心跳往返毫秒 |
| version | 客户端与网关版本号 |
| lastError | 最近一条连接错误摘要 |

### 6.7.5 技能不生效排查

安装技能后若 Agent 仍无法调用相关能力，按下列顺序检查。

**第 1 步：** 确认技能目录下存在 SKILL.md 且非空。
**第 2 步：** 在工具页或办事能力中确认该技能开关为「启用」。
**第 3 步：** 重启网关或刷新 Agent 列表，使元数据重新加载。
**第 4 步：** 在对话中明确提及技能描述中的触发关键词。
**第 5 步：** 查看运行日志是否有技能解析错误。

### 6.8.5 企业合规检查表

建议企业管理员按季度执行下列检查。

| 检查项 | 通过标准 |
| --- | --- |
| 授权有效 | 徽章为已激活且未过期 |
| 账户清单 | 无多余离职账户 |
| Owner 密码 | 已轮换且知晓人员 ≤2 |
| 审计日志 | 无 unexplained CLI 调用 |
| API Key | 未泄露至聊天附件 |

### 6.9.6 本机服务子面板一览

「软件设置 → 本机服务」下常见子面板及用途如下。

| 子面板 | 主要配置 |
| --- | --- |
| 连接 | 自动重连、健康检测、手动连接、复制诊断 |
| 模型配置 | API Key、默认模型、Provider |
| 网关内存上限 | 256～4096MB 预设 |

**6.9.6 补充**

修改连接 URL 或 Token 属于高级操作，错误配置将导致全员无法连接，建议由 Owner 执行。

从 .env 重新加载可在不重启客户端的情况下尝试同步磁盘 Key，若网关已缓存旧 Key 仍需重启网关。

办事能力「同步精选技能」需联网；离线环境请使用本地已有技能包或 U 盘拷贝 skills 目录。

### 6.10 典型操作流程

本节汇总跨模块的端到端操作路径，编号 6.10.x 便于培训演示。

### 6.10.1 首次部署完整流程（管理员）

**第 1 步：** 安装 MSI/DMG 并完成首次启动解压，等待启动屏消失。
**第 2 步：** 在设备授权页复制机器指纹，获取 license.dat 并粘贴激活。
**第 3 步：** 注册管理员账户（注意发行档密码规则），登录进入主界面。
**第 4 步：** 直连版：设置 → 模型配置填写 API Key 并保存，重启网关。
**第 5 步：** 仪表盘确认「本机 · 已连接」，发送测试消息验证对话可用。
**第 6 步：** 可选：技能工坊安装岗位推荐技能；设置 → 办事能力同步精选技能。
**第 7 步：** 可选：配置 Owner 密码策略，向运维人员交接 Owner 凭据。


### 6.10.2 日常对话与办事流程（终端用户）

**第 1 步：** 启动应用（或托盘唤起），确认顶栏已连接。
**第 2 步：** 新建会话，选择合适 Agent 与模型。
**第 3 步：** 输入问题或办事指令；需附件时先添加文件等待 OCR 完成。
**第 4 步：** 观察流式回复；遇命令审批按需允许或拒绝。
**第 5 步：** 办事类任务打开右侧任务侧栏查看步骤，完成后打开产出目录验收。
**第 6 步：** 结束工作后关闭主窗口最小化至托盘，或托盘退出完全关闭。


### 6.10.3 网关异常恢复流程

**第 1 步：** 记录顶栏状态文案与最近操作（如刚修改 Key 或内存上限）。
**第 2 步：** 打开仪表盘查看网关进程卡片，尝试「健康检查」。
**第 3 步：** 若失败，先「停止」再「启动」；若提示冲突则「回收控制权」。
**第 4 步：** 设置 → 本机服务点击「连接服务」，勾选自动重连。
**第 5 步：** 仍失败则「复制诊断」，Owner 查看运行日志，必要时重启应用。
**第 6 步：** 最后手段：托盘退出后重新启动应用；仍不行则重装同版本或升级 MSI。


### 6.10.4 技能安装与验证流程

**第 1 步：** 顶栏进入技能工坊，选择「社区技能」或「推荐技能」。
**第 2 步：** 安装目标技能至工作区，等待成功提示。
**第 3 步：** 打开工具页确认技能开关为启用；或设置 → 办事能力 → 模块管理确认。
**第 4 步：** 返回 Agent 页刷新列表，展开卡片确认「已装技能」计数增加。
**第 5 步：** 新建会话，用自然语言触发技能描述中的场景进行验证。
**第 6 步：** 若不生效，按 6.7.5 节排查并查看运行日志。


### 6.10.5 授权续费流程

**第 1 步：** 到期前登录应用，设置 → 设备授权查看徽章与到期日。
**第 2 步：** 复制机器指纹提交续费申请（与首次相同指纹，除非硬件变更）。
**第 3 步：** 获得新 license.dat JSON 后，在续费输入框完整粘贴。
**第 4 步：** 点击「续费激活」，确认徽章更新且到期日延长。
**第 5 步：** 无需重新安装软件；若续费后仍显示过期，点击「刷新」并重启应用。


### 6.10.6 应用升级流程

**第 1 步：** 对话页停止一切进行中的 AI 生成与办事任务。
**第 2 步：** 设置 → 应用更新 →「检查更新」。
**第 3 步：** 若有新版本，阅读发行说明后点击「安装新版本」。
**第 4 步：** 按 MSI 向导完成覆盖安装，重启应用。
**第 5 步：** 升级后验证：登录、连接、抽样对话、授权状态仍为已激活。


**6.10 流程注意事项**

所有流程假设本机时钟正确，错误系统时间会导致授权与 Token 校验异常。

企业代理环境需额外放行更新 CDN 与 API 端点，否则检查更新或上游模型可能失败。

流程中涉及 Owner 的操作应双人复核，避免误删用户或覆盖 openclaw.json。

培训演示建议使用专用测试账户与测试 license，避免污染生产授权计数。

| 6.10.3 | 管理员/支持 | 5～15 分钟 |

## 7. 常见问题与异常处理

本章汇总 1.3.0 版本用户反馈频率较高的异常现象与推荐排查路径。若下列步骤无法解决，请携带「复制连接诊断」输出联系技术支持。

### 7.1 无法连接本机服务

**现象**：顶栏长期显示「本机 · 未连接」或「异常」，发送消息时提示「请先连接本机服务后再发送」。
**可能原因**：网关进程未启动、端口 18789 被占用、内置运行时损坏、防火墙拦截本地回环连接。
**解决办法**：
1. 打开仪表盘，在「网关进程」卡片点击「启动」，等待状态变为运行中。
2. 点击顶栏「重连」或快捷键 Ctrl/Cmd+Shift+R。
3. 进入「软件设置 → 本机服务」，勾选自动重连与健康检测，点击「连接服务」。
4. 若提示外部冲突，执行「回收控制权」后再次启动。
5. 仍失败时点击「复制诊断」，检查端口占用并尝试重启应用或重装完整安装包。
- 预防：日常保持网关自动重连开启
- 预防：避免手动启动未受管的 openclaw 进程

[截图：问题 1 错误提示]

### 7.2 API Key 未配置导致无法对话

**现象**：发送消息后提示「尚未配置 API Key，对话功能不可用」，或设置页模型列表为空。
**可能原因**：直连版首次使用未填写 Key、.env 写入失败、Key 已过期或被服务商吊销。
**解决办法**：
1. 打开「软件设置 → 本机服务 → 模型配置」，填写有效 API Key 并保存。
2. 点击「从 .env 重新加载」确认磁盘配置已读取。
3. 重启网关使 Provider 配置生效。
4. 在服务商控制台确认 Key 状态、余额与 IP 白名单（如有）。
- 预防：部署当日即配置并验证 Key
- 预防：定期在服务商控制台检查配额

[截图：问题 2 错误提示]

### 7.3 设备授权失败或已到期

**现象**：启动后阻塞在设备授权页，或设置中徽章显示「已到期」「激活失败」。
**可能原因**：license.dat 不完整、签名无效、机器指纹不匹配、授权已超过有效期。
**解决办法**：
1. 在授权页复制最新机器指纹，向管理员重新申请授权。
2. 从纯文本文件完整复制 JSON，粘贴后点击「激活设备」或「续费激活」。
3. 确认系统日期时间正确，避免误判证书有效期。
4. 硬件大幅变更后需重新绑定授权。
- 预防：到期前 30 天续费
- 预防：授权 JSON 通过安全渠道传输

[截图：问题 3 错误提示]

### 7.4 附件上传失败或 OCR 无结果

**现象**：提示文件超过 48MB、附件灰显无法发送、OCR 后无文本或提示识别失败。
**可能原因**：单文件超限、网关未连接、图片分辨率过低、Tesseract 语言包缺失或损坏。
**解决办法**：
1. 将文件压缩至 48MB 以下或拆分多次发送。
2. 确认顶栏已连接本机服务后再添加附件。
3. 对扫描件适当提高 DPI 后重试 OCR。
4. 重装完整发行包以恢复 bundled/tesseract 资源；查看运行日志中 OCR 引擎报错。
- 预防：上传前压缩大文件
- 预防：扫描件使用 300dpi 以上分辨率

[截图：问题 4 错误提示]

### 7.5 会话过期需重新登录

**现象**：操作过程中弹出「会话已过期」对话框，部分 API 返回未授权。
**可能原因**：登录 Token 超过有效期、本机时间跳变、账户被 Owner 重置密码。
**解决办法**：
1. 点击对话框「重新登录」，使用原账户密码登录。
2. 若忘记密码且安装包支持 Owner 代登，由 Owner 在登录页代为登录。
3. Owner 可在深度运维 → 用户管理中重置该用户密码。
4. 避免在多实例同时登录同一账户导致 Token 互相踢出（视部署策略而定）。
- 预防：避免长时间闲置标签页
- 预防：统一由 Owner 管理账户生命周期

[截图：问题 5 错误提示]

### 7.6 上游 403 或模型调用失败

**现象**：对话报错上游 HTTP 403、模型不存在、配额不足或 User-Agent 被拒绝。
**可能原因**：API Key 无效、模型 ID 配置错误、账户欠费、旧版客户端 UA 被服务商拦截。
**解决办法**：
1. 在模型配置页点击「刷新 Key 状态」或重新保存 Key。
2. 切换至已知可用模型测试，排除单一模型下架问题。
3. 登录服务商控制台检查配额与账单。
4. 通过应用内更新安装最新 MSI，修复已知 UA 兼容问题。
- 预防：保持客户端为最新稳定版
- 预防：模型变更后先小流量测试

### 7.7 数据库异常

**现象**：启动或登录时提示「quick_check 未通过」、账户列表为空、会话无法持久化。
**可能原因**：SQLite 文件损坏、强制结束进程导致写入中断、磁盘满或权限不足。
**解决办法**：
1. 完全退出应用（托盘右键退出）后重新启动，观察是否自动修复。
2. 从定期备份恢复 auth/session 相关数据库文件（联系技术支持获取路径）。
3. 检查磁盘空间与数据目录读写权限。
4. 避免在生成或写入过程中通过任务管理器强制结束进程。
- 预防：正常退出应用
- 预防：定期备份数据目录

### 7.8 更新安装被阻塞

**现象**：点击「安装新版本」时提示「请等待当前回复完成或点击停止后再更新」。
**可能原因**：当前会话仍有流式生成或网关任务执行中，安装程序需替换正在使用的二进制文件。
**解决办法**：
1. 在对话页点击「停止」结束当前 AI 生成。
2. 等待任务侧栏无「执行中」步骤。
3. 返回「软件设置 → 应用更新」重新点击安装。
4. 若仍阻塞，退出应用后手动运行下载的 MSI 完成升级。
- 预防：更新前结束所有生成任务
- 预防：可预约维护窗口执行升级

**7.9 通用排障流程**

第一步：确认顶栏连接状态与设备授权有效。

第二步：复制连接诊断与相关错误截图（见 8.4 占位符）。

第三步：查阅运行日志（Owner）获取 ERROR 行时间戳与堆栈。

第四步：尝试重启网关 → 重启应用 → 重装同版本 MSI 逐级升级。

第五步：仍无法解决时，将诊断 JSON、日志片段、license 状态（脱敏）提交技术支持。
